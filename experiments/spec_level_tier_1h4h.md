# 仕様カード: 上位足レベル強度の二値旗（1H/4H・固定ロット裁量向け）

凍結日: 2026-08-01 / 起案: ユーザー（1H裁量・0.01固定ロット・「強度が高いなら張る、低いなら張らない」）

## 背景（既存の材料）
`x_sizing#fixed-lot-tier`（2026-07-24, `experiments/fixed_lot_tier_btc15mL.py`）で、BTC 15m の btc15m_L に対し
強度3層＝ブレイク終値が {前日高値, 直近確定4Hスイング高値} の何本の上か（both/one/neither）が
素Rで単調（meanR +1.307 / +0.948 / +0.177・PF 3.05/2.31/1.21・無作為3分割null 99.9%ile）であることが確認済み。
ただし測定された腕は **0.01/0.02/0.03 の「上盛り」のみ**。本カードは **「弱い層を張らない（skip）」腕**を、
**別の時間足・別銘柄（1H/4H）へ移せるか**を検定する。移植可否そのものが検定対象（構造法則1に真っ向から当たる）。

## 対象セル（5つ）
1. gold 1H  … `data/vantage_xauusd_h1.csv`, `--start 2018-01-01`（疎データ罠。必須）
2. BTC 1H   … `data/vantage_btcusd_h1.csv`, `--start 2022-01-01`
3. BTC 4H   … `data/vantage_btcusd_h1.csv` を `--tf 4h` にリサンプル, `--start 2022-01-01`
4. USDJPY 1H … `data/vantage_usdjpy_h1.csv`, `--start 2000-01-01`
5. USDJPY 4H … `data/vantage_usdjpy_h1.csv` を `--tf 4h`, `--start 2000-01-01`

BTC を 2022-01-01 で切る理由: 暗号資産は2021年まで「平日のみ」の商品で、**前日高値が週末をまたぐ**。
本実験の主変数がまさに前日高値なので、混ぜると水増しになる（CLAUDE.md データ節）。N が減る代償は受け入れる。

## 固定するもの（一切動かさない）
- 入口: ZigZag(2×ATR) Pattern-B 確定足ブレイク・**ロングのみ**（`breakout_wave.py` の既存機構をそのまま import）
- 出口: **RR3 固定**（全セル共通。RR の最適化は本実験の対象外）
- 損切り: L2（構造）
- ロット: 全トレード 0.01 相当＝**R単位で等ウェイト・非複利**（複利も inv-vol も使わない＝固定ロット裁量の実態）
- コスト: gold=価格の0.1%、BTC=$15/往復（絶対額なので `--cost 0` で回し R から後段で `cost/risk` を減算）、
  USDJPY=0.9pip。**素（コスト前）とネット（コスト後）を両方印字**する（「エッジ無し」と「エッジ有・コスト死」は別ラベル）。

## 動かす1レバー
強度旗 = ブレイクの終値が次の2本の**上にあるか**（both / one / neither の3層）:
1. **前日高値**（日足の確定値。当日の足では未来を見ない）
2. **直近の確定4Hスイング高値**（4H足で確定済みのスイング高値。shift 済み・先読み禁止）

**5セルすべてで同一定義**（4H入口のセルでも同じ2本を使う＝移植の検定なので定義を揃える）。

## 出す数字
A. 層別（both/one/neither）: n・n/年・勝率・PF・meanR（中央値と標準偏差も）・素/ネット両方
B. 腕別の固定ロット成績: **総R・maxDD(R)・総R÷maxDD(R)**
   1. 全部張る（flat）
   2. **neither を張らない**（= one・both のみ）← ユーザーが実際にやりたい腕
   3. both のみ張る
C. 年別の層別本数（ON% が特定の時代に偏っていないか）

## 事前登録の合格線（走った後に緩めない）
- **(a) 単調性**: meanR が both > one > neither、かつ both−neither の差が**無作為3分割帰無の95%ile 超**
- **(b) skip腕**: 腕2の 総R÷maxDD(R) が、**同じ本数だけランダムに間引いた帰無の95%ile 超**
- (a)(b) 両方を満たしたセルのみ PASS
- **多重比較の割引**: 5セル中 **3セル以上**が PASS で 🟢。1〜2セルのみなら 🟡（多重比較の産物の可能性）。0セルなら ❌
- **N不足の宣言**: どの層でも n<50 になったセルは「効かない」ではなく **「未検証（N不足）」** と報告する

## 予想（先に書く。外れたら学習が残る）
- gold 1H: 単調性は出るが帰無を超えない（n≈208 を3層に割ると層あたり約70本＝薄い）
- BTC 1H: 超える（同じBTCの拡大足ロングで前日高値フィルタが既に 99.8%ile を出している）
- BTC 4H: N不足で判定不能
- USDJPY 1H/4H: 単調にならない（法則2＝管理相場。レベルは通過されるのでなく跳ね返される側）
- skip腕: both のみは負け、neither を外すのは勝ち（濃縮が倍になる境界が neither|one にあるため）

## 死に方（KILL 時に何が確定するか）
全セル不合格なら「上位足レベルの強度旗は BTC 15m 固有」＝構造法則1の粒度が1つ確定する。
その場合の次の一手は、旗の定義を「超えているか（二値）」から「どれだけ超えているか（ATR正規化した距離）」に
変えて同じ5セルで再検定（btc15m_L で効いたのが二値なのか距離なのかは未分離）。
